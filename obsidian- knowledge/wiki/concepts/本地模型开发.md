# 本地模型开发

> 在本地环境中部署、微调或从零编写 AI 模型的完整方法论，涵盖从用户到开发者的四个能力层次

## 定义

本地模型开发指在本地（个人电脑或私有服务器）而非云端进行的模型全生命周期操作，包括：部署已有模型、微调（Fine-tuning）、从零编写模型架构、以及完整的模型训练与评估。与依赖云端 API 不同，本地模型开发提供数据隐私、离线可用和完全自主可控的能力。

## 四个能力层次

### 层次一：部署开源模型到本地
最快速的上手路径，无需编写代码即可运行社区模型。

| 工具 | 特点 | 适用场景 |
|------|------|----------|
| Ollama | 一键安装，`ollama run` 即可 | 日常对话、实验最快 |
| llama.cpp | C++ 实现，CPU/GPU 均可 | 低配硬件、量化模型 |
| LM Studio | 图形界面 | 新手最友好 |
| vLLM | 高吞吐推理，PagedAttention | 生产环境/API 服务 |

### 层次二：微调（Fine-tuning）
在已有模型基础上，用自有数据调整模型行为。

| 方法 | 显存需求 | 效果 |
|------|----------|------|
| LoRA | 8-16 GB | ⭐⭐⭐⭐ |
| QLoRA | 6-12 GB | ⭐⭐⭐⭐ |
| Full Fine-tune | 24-80 GB | ⭐⭐⭐⭐⭐ |

**推荐工具链**：Unsloth（最快）→ Axolotl（灵活）→ Hugging Face TRL（底层控制）

### 层次三：从零编写模型
理解深度学习本质的核心路径，用 PyTorch 从零实现 Transformer。

**学习路径**：
1. micrograd — 50 行实现自动微分，理解反向传播
2. nanoGPT — ~300 行 PyTorch 实现完整 GPT
3. minbpe — 从零实现 BPE 分词器

### 层次四：完整开发流程
```
数据准备 → Tokenize → 模型设计 → 训练 → 评估 → 量化 → 部署
```

## 硬件建议

| 场景 | 最低配置 | 推荐配置 |
|------|---------|---------|
| 推理 7B 以下 | 8GB RAM | 16GB RAM + RTX 3060 |
| LoRA 微调 7B | 12GB VRAM | RTX 4090 24GB |
| 全参微调 7B | 24GB VRAM | A100 80GB |
| 从零训练小模型 | 同上 | RTX 4090 或云 GPU |

## 选择建议

- **快速得到可用模型** → 部署 / LoRA 微调
- **理解深度学习本质** → 从零写小模型（nanoGPT）
- **做出有竞争力模型** → 在已有模型上微调
- **学术研究新架构** → 从零开始 + 论文复现
