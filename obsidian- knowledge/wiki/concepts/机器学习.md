# 机器学习

> 让计算机从数据中自动学习和改进的学科。人工智能的核心子领域。

## 定义

机器学习（Machine Learning）是人工智能的一个分支，研究如何让计算机系统利用经验（数据）来自动改进性能和学习新技能，而无需进行明确编程。

## 三大学习范式

### 1. 监督学习
- **定义**：从标注数据（输入-输出对）中学习
- **应用**：分类、回归
- **算法**：线性回归、决策树、SVM、神经网络

### 2. 无监督学习
- **定义**：从无标注数据中发现模式
- **应用**：聚类、降维、异常检测
- **算法**：K-means、DBSCAN、PCA、Autoencoder

### 3. 强化学习
- **定义**：通过与环境交互学习最优策略
- **应用**：游戏 AI、机器人控制
- **算法**：Q-learning、DQN、PPO

## 核心概念

| 概念 | 说明 |
|------|------|
| **特征工程** | 将原始数据转化为模型可理解的数值表示 |
| **模型训练** | 使用优化算法（如梯度下降）最小化损失函数 |
| **过拟合** | 模型过于复杂，记住了训练数据的噪声 |
| **欠拟合** | 模型过于简单，无法捕捉数据中的真实模式 |
| **偏差-方差权衡** | 高偏差 = 欠拟合；高方差 = 过拟合 |
| **交叉验证** | 分多份轮换训练/验证，稳健评估模型 |
| **正则化** | 通过惩罚大参数来防止过拟合（L1/L2） |

## 标准流程

```
数据收集 → 数据清洗 → 特征工程 → 模型选择 → 训练 → 评估 → 调参 → 部署
```

## 经典算法

| 算法 | 类型 | 特点 |
|------|------|------|
| 线性回归 | 监督学习 | 简单可解释 |
| 决策树 | 监督学习 | 可解释性好 |
| SVM | 监督学习 | 处理高维数据 |
| K-means | 无监督学习 | 聚类分析 |
| CNN | 深度学习 | 图像处理 |
| RNN/LSTM | 深度学习 | 序列处理 |
| Transformer | 深度学习 | 通用序列建模 |
