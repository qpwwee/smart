# MCP Server

> MCP（Model Context Protocol）是智能体与外部工具集成的标准化协议，核心是让 LLM 运行时发现并使用工具，而非在代码中硬编码每个接口。

## 定义

MCP Server 是基于 Model Context Protocol 的服务端实现，提供标准化的工具调用接口。它定义了智能体如何发现、调用工具以及访问外部资源的协议规范。

MCP 解决了"智能体如何使用工具"的问题——传统 API 是**"打电话问信息"**，每次对接需要读文档、写适配代码；而 MCP 是**"插 USB 设备"**，智能体无需预先知道工具接口细节，接入后即可即插即用。

## 核心机制（三原语）

| 原语 | 方向 | 描述 | 类比 |
|------|------|------|------|
| `list_tools` | 智能体 → 工具 | 获取可用工具列表及其参数 JSON Schema | "查菜单" |
| `call_tool` | 智能体 → 工具 | 调用指定工具并获取执行结果 | "点菜" |
| `read_resource` | 工具 → 智能体 | 工具向智能体推送资源更新通知 | "厨房通知" |

### 工作流程

```
智能体 ──list_tools──→ MCP Server ──→ 返回工具列表（含 Schema）
智能体 ──call_tool────→ MCP Server ──→ 执行工具 ──→ 返回结果
MCP Server ──read_resource──→ 智能体 ──→ 推送状态变更
```

## 演进与关键特性

| 特性 | 描述 |
|------|------|
| **运行时发现** | 无需预知接口细节，运行时通过 `list_tools` 动态发现工具 |
| **有状态 Session** | 支持多轮对话上下文保持，工具调用可依赖前序状态 |
| **原生 SSE 流** | Server-Sent Events 支持实时流式数据传输 |
| **OAuth 2.1 内置** | 企业级认证开箱即用，无需自建认证层 |
| **AAIF 管理** | Linux Foundation 管理，SDK 月下载量 9700 万+ |

**来源**：2025 年由 Anthropic 提出并开源，2026 年捐赠给 AAIF。

## 与 A2A 的互补关系

MCP 和 A2A 解决不同层级的问题，共同构成多智能体系统的完整通信层：

| 维度 | MCP | A2A |
|------|-----|-----|
| 通信方向 | 智能体→工具（垂直） | 智能体↔智能体（水平） |
| 核心语义 | 工具调用与资源访问 | 任务委派与协作 |
| 发现机制 | `list_tools` | Agent Card |
| 状态管理 | Session 状态 | Task 生命周期 |
| 类比 | "插 USB 设备" | "两台电脑联网" |
