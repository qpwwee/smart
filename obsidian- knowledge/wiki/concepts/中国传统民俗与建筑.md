# 中国传统民俗·节日·饮食·服饰·建筑

> 中国人在日常生活中的文化表达——从传统节日到饮食哲学，从服饰演变到建筑智慧。

## 来源

本笔记编译自 [[中国文化概况（精简版）]] Part 3（第 7-10 章）。

## 一、传统节日（Traditional Festivals）

### 主要传统节日

| 节日 | 时间（农历） | 习俗 | 文化内涵 |
|------|-------------|------|----------|
| **春节（Spring Festival）** | 正月初一 | 贴春联、放鞭炮、年夜饭、发红包 | 辞旧迎新，家庭团圆 |
| **元宵节（Lantern Festival）** | 正月十五 | 赏花灯、吃元宵、猜灯谜 | 春节的圆满收官 |
| **清明节（Tomb-Sweeping Day）** | 4月5日前后 | 扫墓祭祖、踏青 | 慎终追远，亲近自然 |
| **端午节（Dragon Boat Festival）** | 五月初五 | 赛龙舟、吃粽子、挂艾草 | 纪念屈原，驱邪祈福 |
| **七夕节（Qixi Festival）** | 七月初七 | 乞巧、拜月 | 中国情人节，源于牛郎织女 |
| **中秋节（Mid-Autumn Festival）** | 八月十五 | 赏月、吃月饼、团圆 | 阖家团圆，思乡之情 |
| **重阳节（Double Ninth Festival）** | 九月初九 | 登高、赏菊、敬老 | 尊老敬老，健康长寿 |
| **腊八节（Laba Festival）** | 腊月初八 | 喝腊八粥 | 祈福丰收 |

### 农历（Lunar Calendar）

中国传统历法（夏历），平年 354/355 天（12 个月），闰年 383/384 天（13 个月）。一个太阳年分为 **24 节气** 以指导农事。纪年使用**天干地支**搭配，60 年一个循环。传说由尧帝创制。

## 二、烹饪文化（Culinary Culture）

### 八大菜系（Eight Major Cuisines）

| 菜系 | 省份 | 特点 | 代表菜 |
|------|------|------|--------|
| **鲁菜** | 山东 | 咸鲜，火候精湛 | 糖醋鲤鱼、葱烧海参 |
| **川菜** | 四川 | 麻辣，百菜百味 | 宫保鸡丁、麻婆豆腐 |
| **粤菜** | 广东 | 清淡，原汁原味 | 白切鸡、烧鹅 |
| **苏菜** | 江苏 | 精细，刀工讲究 | 松鼠鳜鱼、狮子头 |
| **闽菜** | 福建 | 鲜香，汤品见长 | 佛跳墙、荔枝肉 |
| **浙菜** | 浙江 | 清新，鲜嫩爽滑 | 西湖醋鱼、东坡肉 |
| **湘菜** | 湖南 | 香辣，重油重色 | 剁椒鱼头、毛氏红烧肉 |
| **徽菜** | 安徽 | 火候足，讲究食补 | 臭鳜鱼、毛豆腐 |

### 饮食哲学

- **"民以食为天"** — 饮食在中国文化中处于核心地位
- **"药食同源"** — 食物与药物的界限模糊，强调食疗
- **"色香味形"** — 追求视觉、嗅觉、味觉与造型的统一
- **筷子文化** — 中国饮食的标志性餐具

## 三、服饰与装饰（Costume & Adornment）

### 历史演变

| 时期 | 代表性服饰 |
|------|------------|
| **先秦** | 交领右衽、宽袍大袖 |
| **汉** | 曲裾深衣、直裾 |
| **唐** | 开放华丽，齐胸襦裙、胡服影响 |
| **宋** | 清雅简约，褙子 |
| **明** | 恢复汉制，袄裙、马面裙 |
| **清** | 满族服饰主导：旗袍、长袍马褂 |
| **近现代** | 中山装、改良旗袍、唐装 |

### 服饰文化要点

- **汉服（Hanfu）** — 汉民族传统服饰，当代复兴运动
- **旗袍（Cheongsam）** — 源于满族旗装，民国改良为现代旗袍
- **中山装（Zhongshan Suit）** — 孙中山设计，融合中西
- **刺绣（Embroidery）** — 苏绣、湘绣、粤绣、蜀绣四大名绣

## 四、建筑（Architecture）

### 中国传统建筑特征

| 特征 | 说明 |
|------|------|
| **木结构为主** | 榫卯结构，不用铁钉 |
| **中轴对称** | 宫殿、庙宇、四合院均强调中轴 |
| **庭院布局** | 内向院落，天人合一 |
| **飞檐翘角** | 屋顶曲线优美，兼具排水功能 |
| **色彩规制** | 黄色（皇家）、红色（喜庆）、青绿（民间）|

### 代表性建筑

| 建筑 | 时期 | 特点 |
|------|------|------|
| **故宫（紫禁城）** | 明–清 | 世界上最大、最完整的古代木结构建筑群 |
| **长城** | 秦–明 | 世界奇迹，防御工程，逾 20000 公里 |
| **天坛** | 明–清 | 皇帝祭天之所，建筑与宇宙观的完美结合 |
| **颐和园** | 清 | 皇家园林的集大成者 |
| **苏州园林** | 宋–清 | 私家园林，咫尺山水 |
| **四合院** | 元–清 | 北京传统民居，家族伦理的空间化 |
| **土楼** | 宋–清 | 福建客家围屋，集体防御民居 |
| **窑洞** | 上古延续 | 黄土高原传统穴居，冬暖夏凉 |

### 园林艺术

中国园林分两大流派：

| 流派 | 代表 | 特点 |
|------|------|------|
| **北方皇家园林** | 颐和园、承德避暑山庄 | 宏大富丽，中轴对称 |
| **南方私家园林** | 苏州拙政园、留园 | 精巧灵动，曲径通幽 |

核心美学：**"虽由人作，宛自天开"** — 人造景观但追求自然天成。
