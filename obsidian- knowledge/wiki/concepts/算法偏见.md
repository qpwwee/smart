# 算法偏见

> AI 系统因训练数据、模型设计或部署方式而产生的系统性、不公平的偏差，导致对特定群体或个人的差异化对待。

## 定义

算法偏见（Algorithm Bias / AI Bias）是指 [[人工智能]] 系统在数据处理、模型训练或决策输出中产生的**系统性、可复现的不公平偏差**。它不同于随机误差——偏见是有方向性的，持续性地有利于某些群体 [[数据隐私]]而不利于其他群体。

> **关联框架：** [[人工智能伦理]] — 算法偏见直接挑战 UNESCO 原则 1（不伤害）、原则 3（隐私权）、原则 6（透明度）和原则 10（公平与非歧视）。 影响-关系（人工智能伦理**影响**了算法偏见）
>
> **理论根源：** [[机器学习]] 中提出的"归纳偏好（Inductive Bias）"概念——任何有效算法必有偏好，否则无法在等效假设中做选择。算法偏见的伦理问题，本质上是这种技术性偏好被社会不平等数据扭曲后的产物。参见 [[机器学习#核心概念]]。 基于-关系（算法偏见**基于**机器学习的归纳偏好理论）

## 偏见的来源分类

算法偏见不始于模型，也不止于模型。它在 AI 系统的**全生命周期**中产生：

### 1. 数据偏见（Data Bias）— 最根本的来源

| 子类型 | 描述 | 案例 |
|--------|------|------|
| **历史偏见** | 训练数据反映了社会已有的不平等 | 招聘模型学习到「男性更适合理工科」的历史招聘数据 |
| **采样偏见** | 数据不能代表目标人群的分布 | 面部识别模型主要用浅肤色人脸训练 → 对深肤色误判率高出 10-35 倍 |
| **测量偏见** | 用来标记数据的标准本身有偏差 | 用「被捕次数」作为犯罪率的代理指标 → 过度标注少数族裔社区 |
| **标注偏见** | 人工标注者引入主观判断 | 同一张医学影像，不同医生标注结果不一致 |
| **排除偏见** | 某些群体被排除在数据收集之外 | 临床试验数据主要包含男性 → 药物对女性效果评估不准 |

### 2. 模型偏见（Model Bias）— 算法设计层面

- **特征选择偏见**：选择了与敏感属性（种族、性别）高度相关的特征作为预测变量
- **优化目标偏见**：追求整体准确率 → 牺牲少数群体的预测准确性
- **反馈循环**：模型的输出影响未来数据的生成 → 偏见自我强化（例如：预测犯罪率高的区域 → 更多警力部署 → 更多逮捕记录 → 更高预测犯罪率）

### 3. 部署偏见（Deployment Bias）— 使用层面

- **应用情境不匹配**：在 A 场景训练的模型直接用于 B 场景
- **用户反馈偏见**：系统根据用户行为不断调整 → 形成「信息茧房」和「回声室效应」
- **可及性偏见**：某些群体无法使用或不愿使用 AI 服务

## 经典案例

### 面部识别与种族偏见
- **问题：** 2018 年 MIT 研究显示，IBM、微软、旷视的面部识别系统对深色皮肤女性的错误率高达 21-35%，而对浅色皮肤男性的错误率仅 0.8%
- **根源：** 训练数据集（如 ImageNet、LFW）中含有的深色人脸样本远少于浅色人脸
- **UNESCO 关联：** 直接违背原则 10（公平与非歧视）和原则 1（不伤害）

### 招聘算法与性别偏见
- **问题：** 亚马逊 2014 年开发的 AI 招聘工具系统性地降低了女性简历的评分
- **根源：** 模型基于过去 10 年的简历数据训练 → 男性候选人占据绝大多数
- **OECD 关联：** 违背原则 2（人权与民主价值，包括公平和隐私）

### 医疗 AI 与结构性不平等
- **问题：** 2019 年《Science》研究显示，美国医院使用的健康风险预测 AI 系统严重低估了黑人患者的实际健康需求
- **根源：** 模型使用「医疗费用」作为健康需求代理指标 → 黑人患者因历史原因获得更少医疗服务 → 费用更低 → 被标记为「更健康」
- **UNESCO 关联：** 违背原则 1（不伤害）和原则 10（公平）

### 司法 AI 与系统性歧视
- **问题：** COMPAS 累犯预测系统对黑人被告的误判率高于白人被告
- **根源：** 训练数据中的执法记录本身含有系统性执法偏差
- **影响：** 预测结果影响保释、量刑、假释决定 → 形成「司法-算法」恶性循环

## 偏见检测与缓解技术

| 阶段 | 方法 | 说明 |
|------|------|------|
| **数据层** | 数据审计 | 检查训练数据中各群体的分布是否均衡 |
| | 数据增强 | 补充代表性不足的群体的样本 |
| **训练层** | 对抗性去偏 | 训练一个「去偏」模型，使敏感属性不可预测 |
| | 公平性约束 | 在损失函数中加入公平性正则项 |
| | 再加权 | 对不同群体的样本赋予不同的权重 |
| **评估层** | 公平性指标 | 统计均等差异、均等化几率、差异影响比 |
| | 分层评估 | 分别评估模型在不同子群体上的准确率 |
| **部署层** | 持续监控 | 上线后持续追踪模型的公平性指标变化 |
| | 人机协作 | 高危/不公平风险决策保留人类复审渠道 |

### 关键公平性指标

| 指标 | 定义 | 适用场景 |
|------|------|---------|
| **统计均等**（Statistical Parity）| 被分配到正面结果的比例在不同群体中相等 | 雇佣、贷款审批 |
| **均等化几率**（Equalized Odds）| 真正率和假正率在不同群体中相等 | 医疗诊断、司法 |
| **均等化机会**（Equal Opportunity）| 真正率在不同群体中相等 | 面试筛选 |
| **预测均等**（Predictive Parity）| 预测精度的阳性预测值在不同群体中相等 | 风险评估 |
