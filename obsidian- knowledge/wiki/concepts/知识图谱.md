# 知识图谱

> 用图结构表示和存储结构化知识的技术

## 定义

知识图谱（Knowledge Graph）是一种用图结构（节点+边）表示真实世界中实体及其关系的技术，将知识组织成可计算、可推理的形式。

## 核心概念

### 图结构
- **实体（Entity）**：图中的节点，表示真实世界的对象
- **关系（Relation）**：图中的边，表示实体间的关联
- **属性（Property）**：实体和关系的特征描述

### 知识表示
```json
{
  "实体": "清华大学",
  "类型": "大学",
  "位置": "北京",
  "校长": "李路明",
  "成立于": "1911年"
}
```

## 应用场景

- **搜索引擎**：Google Knowledge Graph
- **问答系统**：基于知识图谱的推理问答
- **推荐系统**：利用知识图谱增强推荐
- **[[智能体]]**：知识推理和决策

## 在本项目中的角色

知识图谱是 [[智能体]] 知识管理的重要工具：
- 知识图谱可以增强 [[智能体]] 的推理能力
- 在 [[RAG]] 中，知识图谱可以补充向量检索
- 知识图谱是 [[知识编译]] 的结构化表示方式之一

## 与机器学习的关系

- 知识图谱 **与** [[机器学习]] 互补（图谱推理+统计学习）
- 知识图谱 **使用** [[机器学习]] 进行知识抽取
- 知识图谱 **服务** [[人工智能]] 的知识表示 是-关系（知识图谱**是**人工智能的子概念/应用）
