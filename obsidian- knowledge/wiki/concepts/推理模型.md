# 推理模型

> 具备文本理解和生成能力的大语言模型，用于问答、推理和知识编译

## 定义

推理模型（Inference/Reasoning Model）是能够理解上下文、进行逻辑推理并生成连贯文本的大语言模型。在本项目中，推理模型承担「知识编译器」和「问答引擎」的角色。

## 思考深度档位（Variants）与温度设置

推理模型在 [[OpenCode]] 中以「变体（Variants）」形式支持多档思考深度，可通过 **Ctrl+T** 循环切换。

### 默认档位

| 模型提供商 | 可用档位 | 默认档位 | 说明 |
|-----------|---------|----------|------|
| OpenAI | `none`→`minimal`→`low`→`medium`→`high`→`xhigh` | `high` | 6 档推理力度 |
| Anthropic | `high`、`max` | `high` | 2 档思考预算 |
| Gemini | `high`、`max` | `high` | 2 档思考预算 |
| ~~**Ollama（本项目）**~~ | ~~由模型自身决定~~ | ~~`reasoning: true` 开启推理~~ | ⚠️ 本地推理模型已全部卸载，推理已迁移至云端 |

### Temperature（温度/随机性）

> 控制 AI 响应的创造性与确定性。值越低越集中，越高越多样。

| 范围 | 适用场景 |
|------|----------|
| `0.0 - 0.2` | 代码分析、规划、事实问答（高确定性） |
| `0.3 - 0.5` | 一般开发任务、知识编译（平衡） |
| `0.6 - 1.0` | 头脑风暴、创意写作（高创造性） |

**未指定时各方的默认值：**

| 来源 | 默认值 |
|------|--------|
| OpenCode（未指定时） | 大多数模型 `0`，Qwen 系列 `0.55` |
| Ollama（未指定时） | `0.8` |
| 模型自身 Modelfile | 以 `ollama show --parameters <模型>` 输出为准 |

### 本项目的当前配置

当前 `~/.config/opencode/opencode.json` 中 **未显式设置档位和 temperature**，因此使用上述默认值链。若要自定义，可在 `opencode.json` 中添加：

```json
"gemma4-cn": {
  "name": "gemma4-中文版：26b",
  "id": "gemma4-cn",
  "tool_call": true,
  "reasoning": true,
  "variants": {
    "快速": { "temperature": 0.1 },
    "平衡": { "temperature": 0.5 },
    "深度": { "temperature": 0.3, "reasoning": true }
  }
}
```

## 在 LLM Wiki 中的角色

推理模型是 [[LLM Wiki 方法论]] 的核心引擎： [[Ollama]]

1. **[[Ingest]] 操作**：阅读原始文档 → 提取要点 → 生成结构化 Wiki 页面 使用-关系（推理模型**使用**Ingest）
2. **Query 操作**：理解问题 → 检索相关 Wiki → 综合回答
3. **Lint 操作**：扫描页面 → 发现矛盾/缺失 → 修复建议

## 与嵌入模型的区别

- [[嵌入模型]]：输出向量，用于检索和比较（无生成能力） 使用-关系（推理模型**使用**嵌入模型）
- **推理模型**：输出文本，用于理解和生成（无向量输出）
- 两者互补，嵌入模型负责「找」，推理模型负责「答」
