# 数据隐私

> AI 系统中个人数据的收集、存储、处理与共享应遵循的伦理和法律规范。

## 定义

数据隐私（Data Privacy / Information Privacy）是指个人对其数据——包括身份信息、行为数据、生物特征、基因组信息等——的**控制权、知情权和保护权**。在 [[人工智能]] 语境下，数据隐私的核心矛盾 [[人工智能伦理]]在于：AI 模型需要大量数据才能有效训练，但数据收集和使用过程可能侵害个人隐私权。

> **关联框架：** [[人工智能伦理]] — 数据隐私直接对应 UNESCO 原则 3（隐私权与数据保护）和 OECD 原则 2（人权与民主价值，包括公平和隐私）。 是-关系（数据隐私**是**人工智能伦理的子概念/应用）

## 核心隐私原则

### OECD 隐私框架（1980/2013 更新） [[OECD AI 原则]]

| 原则 | 含义 |
|------|------|
| **收集限制** | 数据收集应合法、公正，且需告知数据主体 |
| **数据质量** | 数据应与使用目的相关、准确、完整 |
| **目的明确** | 收集目的应在收集前明确 |
| **使用限制** | 不得超出收集目的使用 |
| **安全保障** | 采取合理措施防止数据泄露 |
| **公开透明** | 数据处理实践应公开 |
| **个人参与** | 个人有权了解数据持有情况并要求修正 |
| **问责制** | 数据控制者应遵守上述原则 |

### GDPR 核心权利

欧盟《通用数据保护条例》（GDPR, 2018）进一步强化了个人数据权利：

- **知情权** — 被告知数据如何被收集和使用
- **访问权** — 访问自己的数据副本
- **更正权** — 更正不准确的数据
- **删除权（被遗忘权）** — 要求删除个人数据
- **限制处理权** — 限制对个人数据的处理
- **数据可携权** — 在不同服务间转移数据
- **反对权** — 反对基于特定目的的数据处理

## AI 时代的隐私挑战

### 1. 训练数据中的隐私风险

| 风险类型 | 描述 | 案例 |
|---------|------|------|
| **数据泄露** | 训练数据被未授权访问 | 医疗影像数据集被泄露 |
| **重新识别** | 匿名化数据被逆向识别 | Netflix 奖数据集通过行为模式识别人 |
| **模型记忆** | LLM 记忆训练数据中的个人隐私 | GPT 输出中包含真实 email/电话 |
| **推断攻击** | 从模型输出推断训练数据信息 | 成员推断攻击（Membership Inference）|

### 2. 与 AI 伦理的交叉点

- **UNESCO 原则 3（隐私权）** 是 AI 伦理的基石
- **UNESCO 原则 6（透明度）** 与隐私保护之间存在张力（越透明越难保护隐私）
- **算法偏见** 与数据隐私交叉：从数据收集阶段就存在的隐私侵犯可能加剧偏见

### 3. 技术解决方案

| 技术 | 原理 | 应用场景 |
|------|------|---------|
| **差分隐私** | 在数据中添加噪声，保护个体不被识别 | Apple/Samsung 设备数据分析 |
| **联邦学习** | 数据不出本地，仅共享模型梯度 | 医疗 AI、手机输入法 |
| **同态加密** | 在加密数据上直接计算 | 金融风控、医疗诊断 |
| **合成数据** | 生成与真实数据统计特征相似的人工数据 | 模型训练、测试 |
| **数据脱敏** | 移除/替换可识别信息 | 数据共享、发布 |

## 与伦理框架的对应关系

| 框架 | 对应条款 | 数据隐私的要求 |
|------|---------|--------------|
| **UNESCO** | 原则 3（隐私权与数据保护）| 全生命周期保护，建立数据保护框架 |
| **OECD AI** | 原则 2（人权与民主价值）| AI 系统应尊重隐私权 |
| **EU AI Act** | 高风险 AI → 须符合 GDPR | 医疗、执法等场景需严格合规 |
| **中国《个人信息保护法》**| 2021 年实施 | 知情同意、最小必要、目的限制 |
