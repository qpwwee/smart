# 大语言模型（Large Language Model）

> 基于海量文本数据训练的大规模语言模型，能够理解和生成自然语言

## 定义

大语言模型（Large Language Model，LLM）是基于 Transformer 架构、在海量文本数据上进行预训练的深度学习模型，具备强大的自然语言理解和生成能力。其核心特征是"大"——参数规模通常在数十亿到数万亿之间，使模型涌现出小模型不具备的推理、创作、编程等高级能力。

## 核心特征

1. **规模涌现** — 参数量达到一定规模后，模型涌现出小模型不具备的能力（如推理、指令遵循）
2. **预训练 + 对齐** — 先通过自监督学习预训练，再通过 RLHF/RLAIF 等方法对齐人类偏好
3. **上下文学习** — 无需微调，通过 Prompt 中的示例即可学习新任务（In-Context Learning）
4. **多任务通用** — 一个模型即可完成翻译、摘要、编程、问答等多种任务

## 技术架构

| 组件 | 说明 |
|------|------|
| Transformer 解码器 | 主流架构（GPT 系列），自回归生成 |
| Tokenization | BPE / SentencePiece 等分词方法 |
| 位置编码 | RoPE / ALiBi 等旋转位置编码 |
| 注意力机制 | 多头注意力 / GQA / MQA 优化 |
| 对齐训练 | RLHF / DPO / Constitutional AI |
